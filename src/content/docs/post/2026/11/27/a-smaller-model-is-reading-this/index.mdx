## A Model in the Browser

Browsers are beginning to ship small language models. Chrome includes Gemini Nano. Edge exposes
Microsoft's Aion Instruct, a 2.3-billion-parameter model, behind a flag. A page can reach both
through browser APIs: `Summarizer` and `LanguageModel`.

That makes the feature unusually easy to explain. Overfit is a pile of static files on GitHub Pages.
There is no application server to add an inference endpoint to, no API key to protect, and no usage
bill. The model runs on your machine, and the content it reads can stay there too.

Your machine still has to qualify. Think roughly 22 GB of free disk, a capable GPU or 16 GB of
memory, and a desktop browser. Phones are not in the picture. The browser downloads several
gigabytes the first time the feature is used, but it waits until you click. Karl's Edge instance
labelled the machine "VeryHigh" while reporting that no model was loaded. It looked stuck for about
a minute. It was not. Browser models are lazy-loaded: nothing arrives until a page asks, and the
page cannot ask before you press a button.

## Two Buttons

**Summarize** reduces a post to a few useful points. Both controls read the plain-Markdown copy
created for [llms.txt](/llms.txt). That file began as a handoff for text-based tools. Now the next
reader may be a model running a few tabs away from the prose.

**Ask this piece** opens a question box and has more moving parts than the label suggests. The model
first turns the question into a search query. The page sends that query to Overfit's own search index,
which already powers the search box at the top of the site and runs locally in the browser. It can
also query Wikipedia and Hacker News without an API key. A checkbox below the question switches
those external sources off. The resulting answer includes numbered citations, each linked to its
source. The sources and the exact queries used appear beneath it.

This is about as close to web research as a static site can get. Search APIs with stronger guarantees
usually require an account and secret key. A key embedded in browser code is not a secret.

## Needing Big Tech Less

Jan-Lukas Else wrote this week that
[AI made self-hosting fun again](https://janlukas.blog/posts/ai-self-hosting). Coding agents removed
the setup friction that had made his own server feel like too much work: a project he expected to
take a week took half a day. He calls the result "somewhat ironic": big-tech AI lets him depend less
on big tech, while also making a different dependency visible.

Overfit repeats the trick in miniature. A large hosted model helped build the feature, then moved
the inference itself onto the reader's machine. The browser becomes a tiny edge server, supplying
disk, memory, a capable GPU, and often patience. IoT made the same promise: put small intelligence
near the device and loosen its tie to the cloud. It also left us with thermostats and doorbells
bound to vendors, update schedules, and final support dates. Browser models may follow that route,
but they arrive on a general-purpose machine with a much more portable asset: the text.

If your browser supports it, try one summary and one question. The interesting result is not whether
the machine is impressive, but whether the feature makes the original more useful.
